# ADR-072: 건물 도형의 주소 연결은 소재지 시군구 코드도 사용한다

- 상태: accepted
- 날짜: 2026-10-31

## 배경

전국 전체분의 실제 C2 표본에서 같은 주소의 한글 자료 도로 코드는 `112004103113`, 도형의 도로 코드는 `111404103113`이었다. 소재지·법정동·도로명·건물번호가 같고 도형의 소재지 `sig_cd`는 `11200`이다. 원본 한글 ZIP도 `112004103113`을 제공하므로 적재 중 바뀐 값이 아니다. 기존 전체 코드 일치 조건만으로는 이 건물들을 주소 미연결로 판정하고 실제 UI의 건물 도형 조회도 놓친다.

## 결정

- 원본 도형의 `rds_sig_cd`, `rn_cd`, 여기서 생성한 `rncode_full`과 물리 건물관리번호는 보존한다.
- 정합성 C1·C2·C4·C5, 품질 표본 조회와 건물 도형 조회는 기존 도로 코드 일치 조건에 `sig_cd || rn_cd` 일치 조건을 추가한다.
- 건물구분·본번·부번·법정동 10자리 조건은 그대로 유지한다. 도로 코드만 같다고 다른 법정동의 도형을 연결하지 않는다.
- 주소의 26자리 관리번호와 도형의 25자리 물리 건물관리번호를 동일한 키로 간주하지 않는다.
- 기존 도로 관할 코드로 조회하던 요청도 계속 지원한다. 반환하는 원본 도로 코드와 건물관리번호는 바꾸지 않는다.
- 소재지 코드 식과 건물번호·법정동의 B-tree 인덱스를 추가한다. 기존 인덱스는 보존한다. 마이그레이션은 적재가 종료된 유지보수 구간에 실행하고 API 읽기를 유지한다.

## 검증과 범위

실제 PostgreSQL의 임시 테이블에 실제 코드 조합을 넣고 C1·C2, 두 종류 도로 코드 입력의 도형 조회, 다른 법정동 제외, 도로 관할 코드 누락과 실제 연결 키 누락을 검증한다. 원천 자체의 좌표 이상치·기준월 차이와 품질 임계값은 이 변경으로 해결하거나 완화하지 않는다.
